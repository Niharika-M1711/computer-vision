# Computer Vision Projects

Computer vision is where deep learning gets visual — and honestly, 
seeing a model detect objects in real-time never gets old.

These projects focus on real-world applications — detecting objects 
live and reading number plates from vehicles — using state-of-the-art 
architectures like YOLO.

## Projects

| Project | Architecture | Dataset |
|---------|-------------|---------|
| YOLO Object Detection | YOLOv11 | COCO Dataset |
| Number Plate Recognition | YOLO + Tesseract OCR | Custom |

## What I learned

YOLO changed how I think about speed vs accuracy tradeoffs. Most detection 
models are either fast or accurate — YOLO manages to be both, and understanding 
why that architecture works the way it does was genuinely eye-opening.

Number plate recognition was the most practical one — it's the kind of system 
you see in parking lots and toll booths every day. Building it from scratch 
gives you a completely different appreciation for how it works in production.
